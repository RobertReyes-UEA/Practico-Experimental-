Los códigos presentados corresponden a diferentes tecnologías utilizadas en el desarrollo del práctico experimental. En el caso del VHDL, se implementa una compuerta lógica AND que permite comprender los fundamentos del diseño de circuitos digitales en hardware programable, donde las salidas dependen de operaciones lógicas entre entradas. Por otro lado, el código en Python utiliza la librería smbus para establecer comunicación mediante el protocolo I2C con un dispositivo externo desde una Raspberry Pi, permitiendo la lectura de datos y evidenciando la interacción entre hardware y software en sistemas embebidos. Finalmente, el programa en lenguaje C para Arduino muestra el uso de la comunicación serial, enviando mensajes de forma periódica a través del puerto serial, lo cual es fundamental para la transmisión de datos y monitoreo en sistemas electrónicos. En conjunto, estos códigos reflejan la integración de distintas plataformas y lenguajes en el diseño e implementación de sistemas digitales aplicados a entornos reales.
